# Security Policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Use GitHub's private reporting instead: **Security → Report a vulnerability** on this repository.

Include what you found, how to reproduce it and what an attacker could do with it. You'll get a reply within 7 days.

## Scope

Things we especially want to hear about:

- Ways another app or a website could read your transcripts, history or clipboard through Kitflo
- Ways to reach or abuse the local `llama-server` (it should accept only Kitflo's per-launch key)
- Kitflo capturing audio or keys when the dictation key isn't held

## Supported versions

Only the latest commit on `main` gets fixes.
